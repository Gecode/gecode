# Inventory of defaultable members, comparisons, and overload pairs

Measured on feature/breaking-7 at 0858ded74edad1bb5fda4d90cd5967bd537ee8cc
on 2026-11-04. The tools were clang-tidy and libclang from LLVM 22.1.8,
Python 3.15.1, and ripgrep 15.1.0. Sources were unchanged. The scripts are
in the appendix, and their outputs were scratch files under
`build/mc002-inventory/`.

Tasks 003, 004, and 005 apply this record. Its proposed check options and its
row treatments are what those tasks start from; a row they cannot apply
without changing behaviour stays as it is.

## Commands

Every count below names one of these commands and, for a table, the file it
writes. `reproduce.sh` runs them all in this order.

| Name | Command | Writes |

`V` is one of three variants. Each passes a `-config` JSON that replaces
`.clang-tidy`, so no other check runs.

| Variant | Checks | Options |
|---|---|---|
| `default` | `modernize-use-equals-default`, `modernize-use-equals-delete`, `modernize-use-default-member-init`, `cppcoreguidelines-special-member-functions` | defaults (`IgnoreMacros` true, every `Allow*` false) |

nonzero exit as a tool or compile failure. All twelve clang-tidy commands

## Proposed check options

For task 003:

- Enable `modernize-use-equals-default` and `modernize-use-equals-delete`
  with `IgnoreMacros` at its default, true. The `macros` variant adds 4
  diagnostics (T2): one is configuration-dependent, two are cloning
  constructors, and the fourth can be defaulted by hand.
- `modernize-use-equals-default` reports cloning constructors and has no
  option to skip them. The brief puts cloning constructors out of scope for
  `= default`. With `IgnoreMacros` true the check reports 26 of them: the 25
  rows of `tables/T5-R6.md` that are not macros-only, plus the local class at
  `test/int/cumulative.cpp`:616. Proposal: keep them hand-written, each with
  `// NOLINT(modernize-use-equals-default)`. For a class with no fields of
  its own, `X(X&) = default` would call the same base cloning constructor, so
  the user may instead revisit the brief.
- Do not enable `modernize-use-default-member-init`. It reports 357
  diagnostics (T1), each with a fix, and none of them is a special member;
  moving initializers out of constructors is outside this area.
- Do not enable `cppcoreguidelines-special-member-functions`. It reports 476
  diagnostics with default options and 355 with the lenient ones (T3), and
  none has a fix. The largest groups are classes with only a copy
  constructor, most of them cloning constructors, and classes with only a
  non-default destructor (T1b). Adding the other members there adds code
  without changing behaviour.

## equals-default placement and risks

`run.py macros`, then `summarize.py` → `tables/T4-placement.md`. Each
`equals-default` diagnostic of the `macros` variant (345) is joined to its
member in `ast.json` by file and line. "Out of line" means the body is
outside the class.

| Member | in class | out of line, header | out of line, .cpp | not in ast.json | all |
|---|---|---|---|---|---|
| default-ctor | 36 | 195 | 7 | 0 | 238 |
| copy-ctor | 27 | 27 | 6 | 1 | 61 |
| copy-assign | 0 | 1 | 0 | 0 | 1 |
| dtor | 9 | 21 | 15 | 0 | 45 |
| **total** | 72 | 244 | 28 | 1 | 345 |

clang-tidy's `--fix` rewrites a body where it stands. On an out-of-line
definition it writes an out-of-line `= default`. Such a member is
user-provided, so the class stays non-trivial. Task 003 must default each
member on its first declaration, in the class, or remove it, as task 001 did.

`summarize.py` → `tables/T5-risks.md`. A diagnostic can carry several risks.

| Risk | Diagnostics where | count | by member |
|---|---|---|---|
| R1 | default constructor whose class has a field without a default member initializer | 110 | default-ctor 110 |
| R2 | member of an exported class defined in a .cpp | 11 | default-ctor 1, dtor 10 |
| R3 | definition out of line (`--fix` writes an out-of-line `= default`) | 272 | default-ctor 202, copy-ctor 33, copy-assign 1, dtor 36 |
| R4 | member in a generated variable header | 4 | default-ctor 4 |
| R5 | reported only with IgnoreMacros=false | 4 | default-ctor 2, copy-ctor 2 |
| R6 | cloning constructor: a copy constructor taking a non-const reference | 27 | copy-ctor 27 |

- R1: defaulting a user-provided default constructor changes
  value-initialization. `X()` and `X{}` then zero the fields first. A
  defaulted default constructor also stops `const X x;` from compiling when
  a field has no initializer. Task 003 checks each row.
- R2: moving the member into the class changes the symbols the library
  exports. ABI changes are accepted for Gecode 7, and all ten destructors
  are virtual.
- R3: the out-of-line placement described above.
- R4: change `misc/genvarimp.py`, then regenerate.
- R5: the four rows of T2.
- R6: cloning constructors, kept as proposed above.

  decide.

Overload resolution after dropping `!=`:

- C++20 rewrites `a != b` as `!(a == b)` and also tries the reversed
  `!(b == a)`.
- A class that declares a matching `!=` suppresses the reversed `==`
  candidates (P2468). Dropping `!=` therefore makes reversed candidates join.
- For the view families each `==` takes two views of one type. The rewritten
  call is an exact match, which beats the kernel templates that need a
  derived-to-base conversion. The kernel's own templates stay as they are.

```python
#!/usr/bin/env python3
"""Run the special-member checks of one variant with misc/check.py lint coverage.

Usage: run.py BUILD_DIR OUT_DIR JOBS VARIANT
VARIANT is one of default, macros, smf-lenient (see VARIANTS).
Writes OUT_DIR/{config.json,commands.json,tidy.log,parser-actions.log,
lexer-actions.log,parser-hh.log,raw.txt,fixes/,fixes-*.yaml}.
raw.txt has one line per reported diagnostic: path:line:col: check: message.
"""
import json
import re
import subprocess
import sys
from pathlib import Path

ROOT = Path(subprocess.check_output(["git", "rev-parse", "--show-toplevel"], cwd=Path(__file__).parent,
                                    text=True).strip())
LLVM = Path("/opt/homebrew/opt/llvm@22/bin")
TIDY = LLVM / "clang-tidy"
RUNNER = LLVM / "run-clang-tidy"
GENERATED_PARSER = {"gecode/flatzinc/parser.tab.cpp", "gecode/flatzinc/parser.tab.hpp",
                    "gecode/flatzinc/lexer.yy.cpp"}
DEFAULTABLE_CHECKS = ["modernize-use-equals-default", "modernize-use-equals-delete",
                      "modernize-use-default-member-init", "cppcoreguidelines-special-member-functions"]
SPECIAL_MEMBERS = "cppcoreguidelines-special-member-functions"
LENIENT_OPTIONS = ["AllowSoleDefaultDtor", "AllowMissingMoveFunctions",
                   "AllowMissingMoveFunctionsWhenCopyIsDeleted", "AllowImplicitlyDeletedCopyOrMove"]
# Each variant: the checks it enables and the CheckOptions it sets (all others keep their defaults).
VARIANTS = {
    "default": (DEFAULTABLE_CHECKS, {}),
    "macros": (DEFAULTABLE_CHECKS, {f"{check}.IgnoreMacros": "false" for check in DEFAULTABLE_CHECKS}),
    "smf-lenient": ([SPECIAL_MEMBERS], {f"{SPECIAL_MEMBERS}.{option}": "true" for option in LENIENT_OPTIONS}),
}
DIAGNOSTIC = re.compile(r"^(/[^:\n]+):(\d+):(\d+): warning: (.*) \[([\w.,-]+)\]$")


def path_pattern(path: Path) -> str:
    return r"[\\/]".join(re.escape(part) for part in path.as_posix().split("/"))


def action_ranges(source: Path, grammar: str) -> list[list[int]]:
    """Physical line ranges of source that #line maps to grammar (as misc/check.py lint)."""
    ranges, start = [], None
    lines = source.read_text().splitlines()
    for number, line in enumerate(lines, 1):
        directive = re.match(r'#line \d+ "([^"]+)"', line)
        if directive:
            if start is not None and number > start:
                ranges.append([start, number - 1])
            start = number + 1 if Path(directive[1]).name == grammar else None
    if start is not None:
        ranges.append([start, len(lines)])
    if not ranges:
        sys.exit(f"no {grammar} ranges in {source}")
    return ranges


def lint_commands(build_dir: Path, out: Path, jobs: str, checks: str, config: str) -> list[tuple[str, list[str]]]:
    """The four commands of misc/check.py lint, with checks and config in place of .clang-tidy."""
    sep = r"[\\/]"
    excluded = path_pattern(Path("gecode/third-party")) + sep + "|" + "|".join(
        path_pattern(Path(p)) + "$" for p in sorted(GENERATED_PARSER))
    owned = "(gecode|test|examples|tools)" + sep
    source_filter = "^" + path_pattern(ROOT) + sep + "(?!" + excluded + ")" + owned
    header_filter = path_pattern(ROOT) + sep + owned
    generated_headers = path_pattern(build_dir / "gecode/kernel") + sep + r"var-(type|imp)\.hpp$"
    exclude_filter = (sep + path_pattern(Path("gecode/third-party")) + sep + "|" + sep
                      + path_pattern(Path("gecode/flatzinc")) + sep
                      + r"(parser\.tab\.(cpp|hpp)|lexer\.yy\.cpp)$")
    hf = f"({header_filter}|{generated_headers})"
    common = [f"--checks={checks}", f"--config={config}", "--quiet"]
    commands = [("tidy.log", [str(RUNNER), "-clang-tidy-binary", str(TIDY), f"-checks={checks}",
                 f"-config={config}", "-p", str(build_dir), "-j", jobs, "-quiet", "-extra-arg=-UNDEBUG",
                 "-header-filter", hf, "-exclude-header-filter", exclude_filter,
                 "-source-filter", source_filter, "-export-fixes", str(out / "fixes")])]
    for log, generated, grammar in (("parser-actions.log", "parser.tab.cpp", "parser.yxx"),
                                    ("lexer-actions.log", "lexer.yy.cpp", "lexer.lxx")):
        source = ROOT / "gecode/flatzinc" / generated
        line_filter = json.dumps([{"name": str(source), "lines": action_ranges(source, grammar)}])
        commands.append((log, [str(TIDY), "--extra-arg=-UNDEBUG", "-p", str(build_dir), *common,
                         f"--export-fixes={out / ('fixes-' + log.removesuffix('.log') + '.yaml')}",
                         "--line-filter=" + line_filter, str(source)]))
    commands.append(("parser-hh.log", [str(TIDY), "--extra-arg=-UNDEBUG", "-p", str(build_dir), *common,
                     f"--export-fixes={out / 'fixes-parser-hh.yaml'}", f"--header-filter={hf}",
                     f"--exclude-header-filter={exclude_filter}", str(ROOT / "gecode/flatzinc/parser.hh")]))
    return commands


def relative(path: str) -> str:
    return str(Path(path).resolve().relative_to(ROOT))


def main() -> None:
    build_dir = Path(sys.argv[1]).resolve()
    out = Path(sys.argv[2]).resolve()
    jobs = sys.argv[3]
    check_list, options = VARIANTS[sys.argv[4]]
    out.mkdir(parents=True, exist_ok=True)
    (out / "fixes").mkdir(exist_ok=True)
    checks = "-*," + ",".join(check_list)
    config = json.dumps({"Checks": checks, "CheckOptions": options})
    (out / "config.json").write_text(config + "\n")
    commands = lint_commands(build_dir, out, jobs, checks, config)
    with open(out / "commands.json", "w") as f:
        json.dump([c for _, c in commands], f, indent=1)
    raw = []
    for log, command in commands:
        result = subprocess.run(command, cwd=ROOT, stdout=subprocess.PIPE, stderr=subprocess.STDOUT, text=True)
        (out / log).write_text(result.stdout)
        found = [m.groups() for m in map(DIAGNOSTIC.match, result.stdout.splitlines()) if m]
        print(f"{out.name}/{log}: exit {result.returncode}, {len(found)} diagnostics")
        # The config sets no WarningsAsErrors, so a nonzero exit is a tool or compile failure.
        if result.returncode != 0:
            sys.exit(f"{log} failed; see {out / log}")
        raw += found
    with open(out / "raw.txt", "w") as f:
        for path, line, col, message, check in raw:
            f.write(f"{relative(path)}:{line}:{col}: {check}: {message}\n")
    print(f"{out.name}: raw {len(raw)} unique {len(set(raw))}")


if __name__ == "__main__":
    main()
```

#### `libclang_pass.py`

```python
#!/usr/bin/env python3
"""Record classes, members, and comparison operators of the owned code with libclang.

Usage: libclang_pass.py BUILD_DIR OUT_DIR JOBS
Parses the translation units that misc/check.py lint selects, plus
gecode/flatzinc/parser.tab.cpp so that parser.hh is reached, with their compile
commands and -UNDEBUG. Walks declarations in owned files and the generated
variable headers; function bodies are not entered, so local classes are not seen.
Writes OUT_DIR/ast.json: {"classes", "members", "operators", "included"}, each
record once per (USR, file, line).
"""
import glob
import json
import multiprocessing
import re
import subprocess
import sys
from pathlib import Path

ROOT = Path(subprocess.check_output(["git", "rev-parse", "--show-toplevel"], cwd=Path(__file__).parent,
                                    text=True).strip())
LLVM = Path("/opt/homebrew/opt/llvm@22")
sys.path.insert(0, sorted(glob.glob(str(LLVM / "lib/python3*/site-packages")))[-1])
import clang.cindex as ci  # noqa: E402

ci.Config.set_library_file(str(LLVM / "lib/libclang.dylib"))
RESOURCE_DIR = subprocess.check_output([str(LLVM / "bin/clang"), "-print-resource-dir"], text=True).strip()
SOURCE_SUFFIXES = {".c", ".cc", ".cpp", ".cxx"}
GENERATED_PARSER = {"gecode/flatzinc/parser.tab.cpp", "gecode/flatzinc/parser.tab.hpp",
                    "gecode/flatzinc/lexer.yy.cpp"}
PARSER = "gecode/flatzinc/parser.tab.cpp"
K = ci.CursorKind
CLASSES = {K.CLASS_DECL, K.STRUCT_DECL, K.UNION_DECL, K.CLASS_TEMPLATE, K.CLASS_TEMPLATE_PARTIAL_SPECIALIZATION}
SCOPES = {K.NAMESPACE, K.LINKAGE_SPEC, K.UNEXPOSED_DECL} | CLASSES
MEMBERS = {K.CXX_METHOD, K.CONSTRUCTOR, K.DESTRUCTOR, K.CONVERSION_FUNCTION, K.FUNCTION_TEMPLATE}
FUNCTIONS = MEMBERS | {K.FUNCTION_DECL}
COMPARISONS = {"operator==", "operator!=", "operator<", "operator<=", "operator>", "operator>="}
SCALARS = {ci.TypeKind.POINTER, ci.TypeKind.ENUM, ci.TypeKind.MEMBERPOINTER} | {
    kind for kind in ci.TypeKind if ci.TypeKind.VOID.value < kind.value < ci.TypeKind.COMPLEX.value}  # builtins
EXPORT = re.compile(r"\bGECODE_\w*_EXPORT\b")

owned_prefix = str(ROOT) + "/"
generated_headers: set[str] = set()


def is_owned(file) -> bool:
    if file is None:
        return False
    name = file.name
    if name in generated_headers:
        return True
    if not name.startswith(owned_prefix):
        return False
    relative = name[len(owned_prefix):]
    return (relative.split("/")[0] in ("gecode", "test", "examples", "tools")
            and not relative.startswith("gecode/third-party/") and relative not in GENERATED_PARSER)


def rel(name: str) -> str:
    return name[len(owned_prefix):] if name.startswith(owned_prefix) else name


_lines: dict[str, list[str]] = {}


def line_text(name: str, line: int) -> str:
    if name not in _lines:
        _lines[name] = Path(name).read_text(errors="replace").splitlines()
    return _lines[name][line - 1]


def qualified(cursor) -> str:
    names = []
    while cursor is not None and cursor.kind != K.TRANSLATION_UNIT:
        if cursor.kind not in (K.LINKAGE_SPEC, K.UNEXPOSED_DECL):
            names.append(cursor.spelling or "(anonymous)")
        cursor = cursor.semantic_parent
    return "::".join(reversed(names))


def where(cursor) -> dict:
    loc = cursor.location
    return {"file": rel(loc.file.name), "line": loc.line, "column": loc.column}


def extent(cursor) -> dict:
    return {"start": cursor.extent.start.offset, "end": cursor.extent.end.offset,
            "first_line": cursor.extent.start.line, "last_line": cursor.extent.end.line}


def parameters(function) -> list:
    return [c for c in function.get_children() if c.kind == K.PARM_DECL]


def body(function):
    return next((c for c in function.get_children() if c.kind == K.COMPOUND_STMT), None)


def member_kind(cursor) -> str:
    if cursor.kind == K.DESTRUCTOR:
        return "dtor"
    if cursor.kind == K.CONSTRUCTOR:
        if cursor.is_copy_constructor():
            return "copy-ctor"
        if cursor.is_move_constructor():
            return "move-ctor"
        return "default-ctor" if cursor.is_default_constructor() else "ctor"
    if cursor.kind == K.CXX_METHOD and cursor.is_copy_assignment_operator_method():
        return "copy-assign"
    if cursor.kind == K.CXX_METHOD and cursor.is_move_assignment_operator_method():
        return "move-assign"
    return "method"


def definition_shape(function) -> dict:
    """Whether a definition has a constructor initializer list and an empty body."""
    block = body(function)
    if block is None:
        return {}
    head = []
    for token in function.get_tokens():
        if token.extent.start.offset >= block.extent.start.offset:
            break
        head.append(token.spelling)
    after_parameters, depth, started = [], 0, False
    for spelling in head:
        if started and depth == 0:
            after_parameters.append(spelling)
        elif spelling == "(":
            depth += 1
            started = True
        elif spelling == ")":
            depth -= 1
    tokens = sum(1 for _ in block.get_tokens())
    return {"has_initializers": ":" in after_parameters, "empty_body": tokens == 2}


def from_macro(cursor) -> bool:
    """The declaration's expansion line does not spell the member: it comes from a macro."""
    spelling = cursor.spelling.split("<")[0]
    if spelling.startswith("operator"):
        spelling = "operator"
    return spelling not in line_text(cursor.location.file.name, cursor.location.line)


def ref_qualifier(cursor) -> str:
    qualifier = cursor.type.get_ref_qualifier()
    return {ci.RefQualifierKind.LVALUE: "&", ci.RefQualifierKind.RVALUE: "&&"}.get(qualifier, "")


def member_record(cursor) -> dict:
    parent = cursor.semantic_parent
    record = {
        "usr": cursor.get_usr(), "class_usr": parent.get_usr(), "class": qualified(parent),
        "class_is_template": parent.kind in (K.CLASS_TEMPLATE, K.CLASS_TEMPLATE_PARTIAL_SPECIALIZATION),
        "name": cursor.spelling, "kind": member_kind(cursor), "cursor": cursor.kind.name,
        "parameters": [p.type.spelling for p in parameters(cursor)],
        "result": cursor.result_type.spelling,
        "const": cursor.is_const_method(), "ref": ref_qualifier(cursor),
        "virtual": cursor.is_virtual_method(), "static": cursor.is_static_method(),
        "defaulted": cursor.is_default_method(), "deleted": cursor.is_deleted_method(),
        "access": cursor.access_specifier.name.lower(), "definition": cursor.is_definition(),
        "in_class": cursor.lexical_parent is not None and cursor.lexical_parent.kind in CLASSES,
        "macro": from_macro(cursor), **where(cursor),
    }
    if record["definition"]:
        record |= {"extent": extent(cursor), **definition_shape(cursor)}
        block = body(cursor)
        if block is not None:
            record["body"] = extent(block)
    return record


def field_record(field) -> dict:
    tokens = [t.spelling for t in field.get_tokens()]
    after_name = tokens[tokens.index(field.spelling) + 1:] if field.spelling in tokens else []
    return {"name": field.spelling, "type": field.type.spelling, "access": field.access_specifier.name.lower(),
            "scalar": field.type.get_canonical().kind in SCALARS,
            "initialized": "=" in after_name or "{" in after_name}


def class_record(cursor) -> dict:
    record = {"usr": cursor.get_usr(), "class": qualified(cursor), "cursor": cursor.kind.name,
              "definition": cursor.is_definition(), **where(cursor)}
    if record["definition"]:
        loc = cursor.location
        head = " ".join(line_text(loc.file.name, n) for n in range(cursor.extent.start.line, loc.line + 1))
        children = list(cursor.get_children())
        record |= {
            "exported": bool(EXPORT.search(head)),
            "fields": [field_record(c) for c in children if c.kind == K.FIELD_DECL],
            "bases": [{"class": qualified(c.referenced) if c.referenced else c.type.spelling,
                       "type": c.type.spelling, "access": c.access_specifier.name.lower()}
                      for c in children if c.kind == K.CXX_BASE_SPECIFIER],
        }
    return record


def owning_class(function, lexical_class):
    """The class an operator compares: its class, the class it is a friend of, else its first class parameter."""
    if function.semantic_parent is not None and function.semantic_parent.kind in CLASSES:
        return function.semantic_parent
    if lexical_class is not None:
        return lexical_class
    for parameter in parameters(function):
        t = parameter.type
        if t.kind in (ci.TypeKind.LVALUEREFERENCE, ci.TypeKind.RVALUEREFERENCE):
            t = t.get_pointee()
        declaration = t.get_declaration()
        if declaration.kind in CLASSES:
            return declaration
    return None


def operator_record(function, form: str, lexical_class) -> dict:
    owner = owning_class(function, lexical_class)
    block = body(function)
    compared = sorted({c.spelling for c in block.walk_preorder() if c.kind == K.MEMBER_REF_EXPR}) if block else []
    return {
        "usr": function.get_usr(), "name": function.spelling, "form": form,
        "template": function.kind == K.FUNCTION_TEMPLATE,
        "class_usr": owner.get_usr() if owner is not None else "",
        "class": qualified(owner) if owner is not None else "",
        "parameters": [p.type.spelling for p in parameters(function)],
        "result": function.result_type.spelling,
        "const": function.is_const_method(), "definition": function.is_definition(),
        "member_refs": compared, **where(function),
    }


class Collector:
    """Collects records of one translation unit, skipping keys this process already emitted."""

    def __init__(self, seen: set):
        self.seen = seen
        self.records = {"classes": [], "members": [], "operators": [], "included": []}

    def add(self, kind: str, cursor, make, *args):
        loc = cursor.location
        key = (kind, cursor.get_usr(), loc.file.name, loc.line, loc.column)
        if key not in self.seen:
            self.seen.add(key)
            self.records[kind].append(make(cursor, *args))

    def walk(self, cursor, lexical_class=None):
        for child in cursor.get_children():
            if not is_owned(child.location.file):
                continue
            kind = child.kind
            if kind in CLASSES:
                self.add("classes", child, class_record)
                self.walk(child, child)
            elif kind in SCOPES:
                self.walk(child, lexical_class)
            elif kind == K.FRIEND_DECL:
                for friend in child.get_children():
                    if friend.kind in FUNCTIONS and friend.spelling in COMPARISONS:
                        self.add("operators", friend, operator_record, "friend", lexical_class)
            elif kind in FUNCTIONS:
                is_member = child.semantic_parent is not None and child.semantic_parent.kind in CLASSES
                if is_member:
                    self.add("members", child, member_record)
                if child.spelling in COMPARISONS:
                    self.add("operators", child, operator_record, "member" if is_member else "free", None)


class Units:
    def __init__(self, build_dir: Path):
        self.db = {}
        self.entries = json.loads((build_dir / "compile_commands.json").read_text())
        for entry in self.entries:
            self.db.setdefault(str((Path(entry["directory"]) / entry["file"]).resolve()), entry)

    def arguments(self, path: str) -> list[str]:
        entry = self.db[path]
        args = entry["arguments"] if "arguments" in entry else entry["command"].split()
        result, skip = [], False
        for a in args[1:]:
            if skip:
                skip = False
            elif a in ("-o", "-MF", "-MT", "-MQ"):
                skip = True
            elif a not in ("-c", entry["file"], path):
                result.append(a)
        return result + ["-UNDEBUG", "-resource-dir", RESOURCE_DIR]

    def owned_sources(self) -> set[str]:
        names = subprocess.check_output(["git", "ls-files", "--cached", "--others", "--exclude-standard", "-z"],
                                        cwd=ROOT, text=True).split("\0")
        return {str(ROOT / n) for n in names if Path(n).suffix in SOURCE_SUFFIXES
                and not n.startswith("gecode/third-party/") and n not in GENERATED_PARSER}

    def selected(self) -> list[str]:
        """Owned sources in the database, as misc/check.py lint selects them, plus the parser."""
        return sorted(self.owned_sources() & self.db.keys()) + [str(ROOT / PARSER)]


units: Units
seen: set = set()


def start_worker(build_dir: Path) -> None:
    global units
    units = Units(build_dir)
    generated_headers.update(str(build_dir / "gecode/kernel" / n) for n in ("var-type.hpp", "var-imp.hpp"))


def collect(path: str) -> dict:
    unit = ci.Index.create().parse(path, args=units.arguments(path))
    errors = [str(d) for d in unit.diagnostics if d.severity >= ci.Diagnostic.Error]
    if errors:
        return {"error": f"{rel(path)}: {errors[0]}"}
    collector = Collector(seen)
    collector.walk(unit.cursor)
    collector.records["included"] = sorted({rel(i.include.name) for i in unit.get_includes()
                                            if is_owned(i.include)} | {rel(path)})
    return collector.records


def main() -> None:
    build_dir = Path(sys.argv[1]).resolve()
    out = Path(sys.argv[2]).resolve()
    jobs = int(sys.argv[3])
    out.mkdir(parents=True, exist_ok=True)
    start_worker(build_dir)
    paths = units.selected()
    outside = sorted(rel(p) for p in units.owned_sources() - units.db.keys())
    print(f"database: {len(units.entries)} entries for {len(units.db)} files; {len(paths) - 1} owned sources "
          f"selected; outside the database: {', '.join(outside)}")
    result = {"translation_units": [rel(p) for p in paths], "classes": [], "members": [], "operators": [],
              "included": set()}
    keys = {"classes": set(), "members": set(), "operators": set()}
    # imap hands each worker its units in path order and returns them in that order, so a record that differs
    # between units (a class under #ifdef, say) always comes from the first unit in path order that sees it.
    with multiprocessing.Pool(jobs, start_worker, (build_dir,)) as pool:
        for records in pool.imap(collect, paths):
            if "error" in records:
                sys.exit(f"libclang cannot parse {records['error']}")
            result["included"].update(records["included"])
            for kind in keys:
                for record in records[kind]:
                    key = (record["usr"], record["file"], record["line"], record["column"])
                    if key not in keys[kind]:
                        keys[kind].add(key)
                        result[kind].append(record)
    result["included"] = sorted(result["included"])
    for kind in keys:
        result[kind].sort(key=lambda r: (r["file"], r["line"], r["column"], r["usr"]))
    (out / "ast.json").write_text(json.dumps(result, indent=0))
    print(f"ast: {len(paths)} translation units, {len(result['classes'])} classes, "
          f"{len(result['members'])} members, {len(result['operators'])} comparison operators, "
          f"{len(result['included'])} owned files reached")


if __name__ == "__main__":
    main()
```

```python
class Ast:
    """ast.json indexed by USR and location."""

    def __init__(self, path: Path):
        data = json.loads(path.read_text())
        self.translation_units = data["translation_units"]
        self.included = set(data["included"])
        self.members = data["members"]
        self.operators = data["operators"]
        self.by_usr = collections.defaultdict(list)
        for record in self.members:
            self.by_usr[record["usr"]].append(record)
        self.at = collections.defaultdict(list)
        for record in self.members:
            self.at[(record["file"], record["line"])].append(record)
        self.classes = {}
        for record in data["classes"]:
            if record["definition"] or record["usr"] not in self.classes:
                self.classes[record["usr"]] = record


def location(record: dict) -> str:
    return f"{code(record['file'])}:{record['line']}"


def placement(member: dict) -> str:
    if member["in_class"]:
        return "in class"
    return "out of line, .cpp" if member["file"].endswith(".cpp") else "out of line, header"


def uninitialized_fields(ast: Ast, member: dict) -> list[str]:
    record = ast.classes.get(member["class_usr"], {})
    return [f["name"] for f in record.get("fields", []) if not f["initialized"]]


def is_cloning_constructor(member: dict) -> bool:
    """A copy constructor taking a non-const reference: the cloning idiom of spaces and brancher helpers."""
    return member["kind"] == "copy-ctor" and not member["parameters"][0].startswith("const ")


def defaultable(ast: Ast, unique: list[Diagnostic]) -> list[dict]:

    rows = []

            continue
        kind = next(k for text, k in DEFAULT_MESSAGE_KIND.items() if d.message.endswith(" " + text))
        found = [m for m in ast.at[(d.file, d.line)] if m["kind"] == kind and m["definition"]]
        rows.append({"diagnostic": d, "kind": kind, "member": found[0] if found else None})
    return rows

    body.append(["**total**"] + [sum(counts[(k, p)] for k in kinds) for p in places] + [len(rows)])
    return table(["Member"] + places + ["all"], body)

        if (d.file, d.line) in macro:

        if is_cloning_constructor(m):

def undefined_private(ast: Ast, texts: dict[str, str]) -> list[dict]:

    Members a macro declares (Qt's Q_OBJECT) are skipped: moc defines them in generated sources.

# --- const/non-const overload pairs -----------------------------------------

def body_text(member: dict) -> str:
    if "body" not in member:
        return ""
    data = (ROOT / member["file"]).read_bytes()
    return data[member["body"]["start"]:member["body"]["end"]].decode(errors="replace")


def normalized(text: str) -> str:
    """A body without comments, whitespace, and const, to compare the two halves of a pair."""
    text = re.sub(r"//[^\n]*|/\*.*?\*/", "", text, flags=re.S)
    return re.sub(r"\s+|\bconst\b", "", text)


def statements(text: str) -> int:
    """Statements other than assertions."""
    return re.sub(r"\bassert\(.*?\);", "", normalized(text)).count(";")


def definition(ast: Ast, usr: str) -> dict | None:
    return next((r for r in ast.by_usr[usr] if r["definition"]), None)


def declaration(ast: Ast, usr: str) -> dict:
    return next((r for r in ast.by_usr[usr] if r["in_class"]), ast.by_usr[usr][0])


def overload_pairs(ast: Ast) -> list[tuple[dict, dict]]:
    """Members of one class with one name and parameter list, one const and one not, with equal ref-qualifiers."""
    groups = collections.defaultdict(lambda: {True: set(), False: set()})
    for m in ast.members:
        if m["kind"] == "method" and m["cursor"] == "CXX_METHOD":
            groups[(m["class_usr"], m["name"], tuple(m["parameters"]), m["ref"])][m["const"]].add(m["usr"])
    pairs = []
    for key in sorted(groups):
        both = groups[key]
        if len(both[True]) == 1 and len(both[False]) == 1:
            pairs.append((declaration(ast, next(iter(both[False]))), declaration(ast, next(iter(both[True])))))
    return pairs


def derived_classes(ast: Ast) -> dict[str, list[dict]]:
    """Class name -> class definitions that name it as a direct base."""
    derived = collections.defaultdict(list)
    for record in ast.classes.values():
        for base in record.get("bases", []):
            derived[base["class"]].append({**record, "base_access": base["access"]})
    return derived


def address_taken(texts: dict[str, str], cls: str, name: str) -> list[str]:
    short = re.escape(cls.rsplit("::", 1)[-1])
    spelled = re.escape(name) if not name.startswith("operator") else r"operator\s*" + re.escape(name[8:])
    # An address is taken after =, (, comma, {, or return, and is not followed by a call or parameter list.
    found = re.compile(r"(?:[=(,{]|\breturn)\s*&\s*(\w+::)*" + short + r"(<[^>]*>)?::" + spelled
                       + r"(?!\w)(?!\s*\()")
    return sorted(n for n, t in texts.items() if found.search(t))


def pair_facts(ast: Ast, texts: dict[str, str], derived: dict, pair: tuple[dict, dict]) -> dict:
    mutable, const = pair
    defs = [definition(ast, m["usr"]) for m in pair]
    bodies = [body_text(d) if d else "" for d in defs]
    names_in_derived = []
    for d in derived.get(mutable["class"], []):
        shadowing = {m["name"] for m in ast.members if m["class_usr"] == d["usr"]} & {mutable["name"]}
        names_in_derived.append((d, bool(shadowing)))
    cls = ast.classes.get(mutable["class_usr"], {})
    return {
        "mutable": mutable, "const": const,
        "same_result": mutable["result"].replace("const ", "") == const["result"].replace("const ", ""),
        "virtual": mutable["virtual"] or const["virtual"], "static": mutable["static"] or const["static"],
        "in_cpp": any(d is not None and d["file"].endswith(".cpp") and d["file"] != m["file"]
                      for m, d in zip(pair, defs)),
        "exported": bool(cls.get("exported")),
        "address": address_taken(texts, mutable["class"], mutable["name"]),
        "derived": len(names_in_derived),
        "shadowed": [d["class"] for d, s in names_in_derived if s],
        "nonpublic_bases": [d["class"] for d, _ in names_in_derived if d["base_access"] != "public"],
        "identical": bool(bodies[0]) and normalized(bodies[0]) == normalized(bodies[1]),
        "forwarding": "const_cast" in bodies[0] or "as_const" in bodies[0],
        "statements": max(statements(b) for b in bodies),
        "undefined": [m for m, d in zip(pair, defs) if d is None],
    }


def pair_treatment(facts: dict) -> tuple[str, str]:
    """Convert only when one explicit-object member removes a duplicated multi-statement body or a const_cast."""
    if facts["virtual"] or facts["static"]:
        return "keep", "virtual or static: an explicit-object member cannot be either"
    if facts["undefined"]:
        return "keep", "one half has no definition in the parsed code"
    if facts["address"]:
        return "keep", "address taken: it would become a function pointer"
    if facts["in_cpp"]:
        return "keep", "defined in a .cpp: a template member must move to a header"
    if facts["forwarding"]:
        return "convert", "removes the const_cast forwarding"
    if facts["identical"] and facts["statements"] > 1:
        return "convert", "removes a duplicated multi-statement body"
    if facts["identical"]:
        return "keep", "one statement besides assertions: the merged template is not shorter"
    return "keep", "the bodies differ beyond const"


def pair_table(rows: list[dict]) -> str:
    body = []
    for f in rows:
        m, c = f["mutable"], f["const"]
        treatment, reason = f["treatment"]
        body.append([
            code(m["class"]), code(m["name"] + "(" + ", ".join(m["parameters"]) + ")" + (" " + m["ref"] if m["ref"]
                                                                                       else "")),
            location(m), location(c), code(m["result"]) + " / " + code(c["result"]),
            "yes" if f["same_result"] else "no",
            "virtual" if f["virtual"] else "static" if f["static"] else "",
            (f"{f['derived']}" + (f", shadowed in {', '.join(code(s) for s in f['shadowed'])}" if f["shadowed"] else "")
             + (f", non-public base of {', '.join(code(s) for s in f['nonpublic_bases'])}"
                if f["nonpublic_bases"] else "")),
            ", ".join(code(a) for a in f["address"]) or "no",
            ("cpp" if f["in_cpp"] else "") + (" exported" if f["exported"] else ""),
            "yes" if f["identical"] else "no", f["statements"], treatment, reason])
    return table(["Class", "Member", "Non-const", "Const", "Results (non-const / const)", "Same type up to const",
                  "Virtual/static", "Derived classes", "Address taken", ".cpp / exported", "Identical up to const",

# --- comparison operators ----------------------------------------------------

VIEW_FILE = re.compile(r"^gecode/(kernel|int|set|float)/view(\.hpp|/)")
EXPRESSION_RESULTS = re.compile(r"\b(LinIntRel|LinFloatRel|BoolExpr|SetRel|SetCmpRel)\b")


def family(op: dict) -> str:
    """The row a comparison operator belongs to: an operator family, else the class it compares."""
    if EXPRESSION_RESULTS.search(op["result"]):
        return "minimodel expressions returning " + EXPRESSION_RESULTS.search(op["result"])[1]
    if "FloatVal" in op["class"] or any("FloatVal" in p for p in op["parameters"]):
        return "Gecode::FloatVal"
    view = VIEW_FILE.match(op["file"])
    if view:
        return f"{view[1]} views"
    return op["class"] or "(no class)"


def heterogeneous(op: dict) -> bool:
    types = [re.sub(r"\bconst\b|&|\s", "", p) for p in op["parameters"]]
    if op["form"] == "member":
        types.append(re.sub(r"<.*", "", op["class"].rsplit("::", 1)[-1]))
        types = [re.sub(r"<.*", "", t.rsplit("::", 1)[-1]) for t in types]
    return op["template"] or len(set(types)) > 1


def comparison_rows(ast: Ast) -> list[dict]:
    """One row per comparison family or class, merging the declarations and definitions of each operator."""
    by_usr = collections.defaultdict(list)
    for op in ast.operators:
        by_usr[op["usr"]].append(op)
    rows = collections.defaultdict(lambda: {"operators": collections.Counter(), "locations": [], "forms": set(),
                                            "compared": set(), "heterogeneous": False, "bool": True, "classes": set()})
    for usr, ops in by_usr.items():
        first = next((o for o in ops if o["form"] == "friend"), ops[0])
        row = rows[family(first)]
        row["operators"][first["name"][8:]] += 1
        row["locations"] += [(o["file"], o["line"]) for o in ops]
        row["forms"].add(first["form"] + (" template" if any(o["template"] for o in ops) else ""))
        for o in ops:
            row["compared"].update(o["member_refs"])
        row["heterogeneous"] |= any(heterogeneous(o) for o in ops)
        row["bool"] &= all(o["result"] == "bool" for o in ops)
        if first["class_usr"]:
            row["classes"].add(first["class_usr"])
    return [{"family": name, **row} for name, row in sorted(rows.items())]


def fields_of(ast: Ast, row: dict) -> list[str]:
    if len(row["classes"]) != 1:
        return []
    record = ast.classes.get(next(iter(row["classes"])), {})
    return [f["name"] for f in record.get("fields", [])]


def fields_read(fields: list[str], read: set[str]) -> str:
    """The fields the definitions read directly, out of all fields of the one compared class."""
    if not fields:
        return "—"
    used = [code(f) for f in fields if f in read]
    return (", ".join(used) or "—") + " of " + ", ".join(code(f) for f in fields)


def short_locations(locations: list[tuple[str, int]]) -> str:
    by_file = collections.defaultdict(list)
    for file, line in sorted(set(locations)):
        by_file[file].append(line)
    if len(by_file) > 4 or sum(len(v) for v in by_file.values()) > 8:
        return f"{len(set(locations))} lines in {len(by_file)} files"
    return "; ".join(code(f) + ":" + ",".join(map(str, lines)) for f, lines in by_file.items())


def comparison_table(ast: Ast, rows: list[dict], treatments: dict) -> str:
    body = []
    for row in rows:
        treatment, reason = treatments.get(row["family"], ("**unclassified**", ""))
        operators = ", ".join(code(o) + (f" ×{n}" if n > 1 else "") for o, n in sorted(row["operators"].items()))
        body.append([code(row["family"]), short_locations(row["locations"]), operators, ", ".join(sorted(row["forms"])),
                     fields_read(fields_of(ast, row), row["compared"]), "yes" if row["heterogeneous"] else "no",
                     "yes" if row["bool"] else "no", treatment, reason])
    return table(["Class or family", "Lines", "Operators", "Form", "Fields read directly, of fields",
                  "Heterogeneous", "Returns bool", "Treatment", "Reason"], body)

def ripgrep(out: Path) -> dict[str, set[tuple[str, int]]]:
    """Run each search over gecode/, test/, examples/, and tools/; keep (file, line) of each hit."""
    out.mkdir(exist_ok=True)
    hits = {}
    for name, arguments in RG_SEARCHES.items():
        result = subprocess.run(["rg", "-n", *arguments, *RG_EXCLUDES, "gecode", "test", "examples", "tools"],
                                cwd=ROOT, stdout=subprocess.PIPE, text=True)
        lines = sorted(result.stdout.splitlines())
        (out / f"{name}.txt").write_text("".join(line + "\n" for line in lines))
        hits[name] = {(f, int(n)) for f, n, *_ in (line.split(":", 2) for line in lines)}
    return hits


def write(out: Path, name: str, text: str) -> None:
    (out / name).write_text(text)


def tidy_tables(tables: Path, variants: dict, fixes: set) -> list[Diagnostic]:
    """T1-T3; returns the diagnostics that only IgnoreMacros=false reports."""
    write(tables, "T1-counts.md", check_counts(variants))
    write(tables, "T1b-messages.md", message_counts(variants, fixes))
    delta, delta_list, macro_added = macro_delta(variants)
    write(tables, "T2-macros.md", delta)
    write(tables, "T2b-macros-list.md", delta_list)
    write(tables, "T3-lenient.md", lenient_counts(variants))
    print(f"macros adds {len(macro_added)}; default exports fixes on {len(fixes)} (file, line, check) keys")
    return macro_added


def special_member_tables(tables: Path, ast: Ast, texts: dict, unique: list[Diagnostic],
                          macro_added: list[Diagnostic]) -> None:
    """T4, T5, and the manual candidates M1-M4."""
    rows = defaultable(ast, unique)
    write(tables, "T4-placement.md", placement_table(rows))
    risks = risk_rows(ast, rows, macro_added)
    write(tables, "T5-risks.md", risk_summary(risks))
    for key in ("R1", "R2", "R4", "R5", "R6"):
        write(tables, f"T5-{key}.md", risk_list(ast, risks.get(key, [])))
    print(f"equals-default rows {len(rows)}, not in ast.json {sum(r['member'] is None for r in rows)}, risks "
          + " ".join(f"{k} {len(v)}" for k, v in sorted(risks.items())))
    write(tables, "M1-moves.md", manual_moves(ast))
    undefined = undefined_private(ast, texts)
    write(tables, "M2-undefined.md", undefined_table(undefined))
    write(tables, "M3-defaults.md", out_of_line_defaults(ast))
    unreached = unreached_headers(ast, texts)
    write(tables, "M4-unreached.md", "".join(f"- {code(n)}\n" for n in unreached))
    print(f"translation units {len(ast.translation_units)}, owned files reached {len(ast.included)}, "
          f"undefined private {len(undefined)}, unreached headers {len(unreached)}")


def comparison_tables(tables: Path, ast: Ast, comparison_hits: set) -> None:
    rows = comparison_rows(ast)
    write(tables, "C-comparisons.md", comparison_table(ast, rows, COMPARISON_TREATMENTS))
    missed = sorted(comparison_hits - {(o["file"], o["line"]) for o in ast.operators})
    write(tables, "C-not-in-ast.md", "".join(f"- {code(f)}:{n}\n" for f, n in missed))
    print(f"comparison rows {len(rows)}, operators {len({o['usr'] for o in ast.operators})}, "
          f"rg lines {len(comparison_hits)} not in ast.json {len(missed)}")


def pair_tables(tables: Path, ast: Ast, texts: dict) -> None:
    derived = derived_classes(ast)
    pairs = [pair_facts(ast, texts, derived, p) for p in overload_pairs(ast)]
    for facts in pairs:
        facts["treatment"] = PAIR_OVERRIDES.get((facts["mutable"]["file"], facts["mutable"]["name"]),
                                                pair_treatment(facts))
    write(tables, "P-pairs.md", pair_table(pairs))
    treatments = collections.Counter(f["treatment"] for f in pairs)
    print(f"overload pairs {len(pairs)}: " + "; ".join(f"{t} ({r}) {n}" for (t, r), n in sorted(treatments.items())))


def main() -> None:
    directory = Path(sys.argv[1]).resolve()
    tables = directory / "tables"
    tables.mkdir(exist_ok=True)
    variants = {v: diagnostics(directory / v) for v in VARIANTS}
    for v, (raw, unique) in variants.items():
        print(f"{v}: raw {raw.total()} unique {len(unique)}")
    macro_added = tidy_tables(tables, variants, fixable(directory / "default"))
    ast = Ast(directory / "ast.json")
    texts = owned_texts()
    hits = ripgrep(directory / "rg")
    for name, found in hits.items():
        print(f"rg {name}: {len(found)} lines")
    special_member_tables(tables, ast, texts, variants["macros"][1], macro_added)
    comparison_tables(tables, ast, hits["comparisons"])
    pair_tables(tables, ast, texts)


if __name__ == "__main__":
```
